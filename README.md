# Binance Sentinel

An AI-powered Binance market monitoring agent designed to analyze market data and provide actionable market signals.

## Overview

Binance Sentinel monitors Binance market data and processes it through an automated analysis workflow.

The goal is to provide traders with a simple agent that can:

* Retrieve live Binance market data
* Monitor selected trading pairs
* Analyze current market conditions
* Generate structured market signals
* Present the result directly in the terminal

## Features

* Real-time Binance price monitoring
* Automated market analysis
* Lightweight Node.js implementation
* Binance public API integration
* Terminal-based agent interface
* Designed for fast market observation

## Tech Stack

* Node.js
* JavaScript
* Binance API

## Installation

Clone the repository:

```bash
git clone https://github.com/squit9/binance-sentinel.git
cd binance-sentinel
```

Install dependencies:

```bash
npm install
```

## Run

Start Binance Sentinel with:

```bash
node index.js
```

The agent will connect to Binance market data and display the analysis in the terminal.

## Project Goal

Binance Sentinel is built as an autonomous market-monitoring agent for the Binance Agent challenge.

The project focuses on turning raw market data into useful, structured information that can help users understand current market conditions faster.
